# Gemini (Gem) instructions: planning mode

For the Gemini web app, use the same instructions as `chatgpt-instructions.md`: plan in chat, and have the
user run the engine locally and upload `candidates.json` / `result.json`.

For **Gemini CLI**, there's nothing to paste. Run `gemini` inside the skill folder. `GEMINI.md` loads
`SKILL.md`, and Gemini CLI runs `python scripts/cli.py ...` with its shell tool (approve the commands
when it asks).
